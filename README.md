# RustCraft (Fabric 1.16.5)

Механіки Rust у Minecraft: спрага, айрдропи, спальний мішок, бинти й аптечки, металеві інструменти, сірчана та металева руди.

## Збірка через GitHub
1. Створи новий репозиторій на github.com.
2. Завантаж у нього ВСІ файли з цієї папки (разом із `.github/workflows/build.yml`).
3. Відкрий вкладку **Actions** -> workflow **build** -> дочекайся зеленої галочки (2-5 хв).
4. Відкрий завершений запуск -> внизу **Artifacts** -> **RustCraft-jar** -> скачай.
5. У zip візьми `rustcraft-1.2.0.jar` (без `-sources`) і поклади в `mods/` разом з Fabric API 0.42.0+1.16.

Якщо збірка впала, відкрий червоний крок і надішли мені текст помилки.

## Будівництво (Креслення / Building Plan)
- Креслення видається при першому заході, також `/rust plan` або крафт: 2 папір + паличка.
- ПКМ по блоку: поставити вибрану частину. Сітка 3x3 блоки.
- Shift + ПКМ: наступна частина (фундамент, трикутний фундамент, підлога, трикутна підлога, стіна, дверний проріз, віконна рама, сходи).
- ПКМ у повітря: матеріал (дерево, камінь, метал). Ціна: дошки, бруківка або металеві уламки.
- Зелені частинки = можна поставити, червоні = не можна. Повернення трикутника та сходів залежить від того, куди ти дивишся.

## Авто-компіляція
Збірка запускається сама після кожного push. Готовий jar з'являється у вкладці **Releases** репозиторію (build-1, build-2, ...), а також в Actions -> Artifacts.
